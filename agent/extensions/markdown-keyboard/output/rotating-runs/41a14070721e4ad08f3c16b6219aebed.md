# World Models

AI systems do not merely predict tokens; they construct provisional realities for choosing what to do next. A world model turns patterns into expectations about causes, objects, agents, and consequences. Joined to tools, those expectations become operational: search retrieves evidence, code tests hypotheses, and sensors correct imagined states.

Yet capability encounters generative friction. Every API, permission, delay, price, and failure constrains what fluent output can accomplish. This resistance can be useful: it forces an agent to compare simulation with reality instead of mistaking eloquence for success.

Affordances shape that test. What an interface reveals, hides, or permits defines the practical horizon of action. Behavioral orientation arises from goals, rewards, defaults, institutional rules, and anticipated judgment. These forces direct attention toward certain possibilities and away from others. The urgent question is not whether AI represents the world accurately, but whose purposes its tools, interfaces, and imagined futures are ultimately designed to serve.
