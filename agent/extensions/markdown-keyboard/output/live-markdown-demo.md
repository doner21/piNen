# The Hidden  Politics of AI World Models

AI world models do more than predict what comes next. They encode which objects, actions, and outcomes appear possible, valuable, or invisible. Connected to tools, these compressed realities become operational: a model can search, calculate, purchase, persuade, or delegate. Errors then escape the chat box and enter institutions.

Tool use is often framed as capability, but every interface supplies affordances and exclusions. A button invites one action; an absent field suppresses another. Generative friction - delays, confirmations, costs, and pauses for human judgment - may resemble inefficiency, yet it can be governance in miniature.

The central question is behavioral orientation: toward whose goals is the system nudged, and by which rewards, defaults, or data? Fluency can hide that orientation by making contingent choices sound natural. Responsible design should expose assumptions, constrain irreversible action, and preserve meaningful refusal.
