# Graphify Brain

This directory is a **placeholder only** in the piNen harness.

No project memories, knowledge graphs, Graphify reports, wiki pages, or graph data are committed to this repository. The Graphify Brain starts empty for each user.

When you run Pi with this harness:
- Graphify builds and stores project knowledge graphs in this directory locally.
- The `graphify-brain/.gitkeep` file ensures the directory is tracked, but all graph artifacts (JSON, Markdown reports, wiki pages) are gitignored.
- Your project memories are private and never published unless you explicitly add and commit them.

See `docs/HARNESS_ARCHITECTURE.md` for more on how Pi uses Graphify.
